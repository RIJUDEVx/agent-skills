# Word swaps

Lookup tables for rules 7, 26, and 31. Find the word, use the plain word instead.

## Rule 7. AI vocabulary

| Word | Use instead |
| --- | --- |
| additionally | also, or delete it |
| crucial | key, or name the thing |
| delve into | look at, dig into |
| enduring | lasting |
| enhance | improve |
| foster | build, encourage |
| garner | get, collect |
| interplay | effect on each other |
| intricate | complex, or the specific detail |
| landscape (abstract) | field, market, area |
| pivotal | key |
| showcase | show, demo |
| tapestry (abstract) | mix of parts |
| testament to | proof of |
| underscore | show, make clear |
| vibrant | bright, lively, busy |

## Rule 26. Abstract metaphor nouns

| Word | Use instead |
| --- | --- |
| substrate | base, underlying layer |
| wedge in | add |
| vector | way, method, direction |
| locus | place, spot |
| vantage | viewpoint, advantage |
| nexus | center, connection point |
| primitive (as a noun) | basic type, building block |
| harness (as a metaphor) | wrapper, runner, the thing that drives it |
| surface (as in "API surface") | endpoints, functions |
| bedrock | base layer |
| scaffolding (as a metaphor) | setup code, temp files |
| modality | mode, channel |
| paradigm | model, approach |
| gold-plating | more than the job needs |
| ratchet (as a metaphor) | the mechanism's real name, or "a limit that only tightens" |
| evacuate (for moving code) | move out |
| endgame | last phase |
| north star | the target metric |
| flywheel | loop |

| Word | Use instead |
| --- | --- |
| utilize | use |
| leverage | use |
| facilitate | help |
| numerous | many |
| in the event that | if |
| in order to | to |
| due to the fact that | because |
